# LLD
LLD (Low-Level Design)


### LLD learning approach

We'll progress from fundamentals → patterns → complete interview problems:

1. **LLD Fundamentals**

   * OOP principles
   * SOLID principles
   * Composition vs inheritance
   * Interfaces / abstractions
   * Encapsulation
   * Coupling & cohesion
   * UML/class diagrams

2. **Design Patterns**

   * Strategy
   * Factory / Abstract Factory
   * Builder
   * Observer
   * Decorator
   * Adapter
   * State
   * Command
   * Template Method
   * Chain of Responsibility
   * Singleton
   * Repository, etc.

3. **LLD Problem Solving**

   * Parking Lot
   * Elevator System
   * BookMyShow / Movie Booking
   * Splitwise
   * ATM
   * Vending Machine
   * Tic-Tac-Toe
   * Snake & Ladder
   * Chess
   * Car Rental
   * Notification System
   * Ride Booking, etc.

4. **Interview-style implementation**

   * Requirements
   * Identify entities/classes
   * Relationships
   * Interfaces
   * Apply SOLID
   * Identify appropriate design patterns
   * Class diagram
   * Code in **TypeScript/JavaScript**, since that aligns with your backend stack
   * Discuss extensibility and trade-offs
   * Handle interviewer follow-up questions


We can start with **OOP principles and SOLID**, which will form the foundation for everything that follows.
